EYN-OS Command Help
==================

Filesystem Commands:
-------------------
  cd              - Change the current directory.
  copy            - Copy a file from source to destination.
  create          - Create a file or directory.
  del             - Delete a file from the filesystem.
  deldir          - Delete an empty directory.
  delete          - Delete a file or directory.
  fatfix          - Repair FAT32 directory entry flags.
  fscheck         - Check filesystem integrity.
  head            - Print the first lines of a file.
  ls              - Run the ls command.
  makedir         - Create a new directory.
  move            - Move a file from source to destination.
  pwd             - Print the current working directory.
  read            - Run the read command.
  size            - Show the size of a file in bytes.
  tail            - Print the last lines of a file.

System Commands:
---------------
  clear           - Clear terminal output.
  drive           - Drive selection helper.
  exit            - Exits the kernel and shuts down the system.
  help            - Display command help.
  init            - Initialize core services.
  lsata           - List detected logical drives.
  portable        - Show portability optimization status.
  serialtest      - Serial output test (userland).
  ver             - Show system version information.

Network Commands:
----------------
  e1000           - Intel e1000 utilities.
  e1000probe      - Probe Intel e1000 NIC.
  netcfg          - Network configuration command.
  netstat         - Show network status.
  pciscan         - Scan PCI devices.
  ping            - Send ICMP echo requests.

Memory Commands:
---------------
  memory          - Memory management and testing.
  memory_stats    - Show predictive memory statistics.
  mmap            - Memory map a file for zero-copy access.
  msync           - Synchronize memory-mapped file to disk.
  munmap          - Unmap a memory-mapped file.
  pagingguards    - Install optional paging guards.
  predict         - Predictive memory management.

GUI/Window Commands:
-------------------
  clearbg         - Clear background image for focused tile.
  draw            - Open the draw canvas editor.
  kstats          - Legacy kernel stats GUI (migrated default is userland 'stats').
  kwin_test       - Legacy kernel window-test command (migrated default is userland 'win_test').
  rect            - Draw a rectangle.
  setbg           - Set background image for focused tile.
  setfont         - Set runtime system font (.hex/.otf/.ttf).
  stats           - Open the stats GUI.
  theme           - Open the theme editor.
  title           - Run the title command.
  view            - Dispatch a file to a view backend from /.view.
  win_test        - Open compositor window test.

Development Commands:
--------------------
  assertfail      - Trigger an assertion failure (ASSERT).
  crashlog        - Inspect and clear crashlog records.
  error           - Display command error status.
  hexdump         - Hex dump file bytes.
  log             - Enable or disable shell logging.
  panic           - Trigger a kernel panic for diagnostics.
  pf              - Intentionally trigger a page fault.
  ring3           - Switch to ring 3 and run a tiny user-mode stub.
  run             - Run a native program, .uelf, or script.
  validate        - Show input validation status and tests.

Utility Commands:
----------------
  alias           - Create or remove command aliases.
  breakout        - Arcade brick-breaker with paddle controls.
  calc            - Integer calculator supporting + - * /.
  cat             - Print a file to stdout.
  diskmgr         - Manage logical drives from userland.
  download        - Download a file over HTTP/1.1 or HTTPS/TLS (GET only) with DNS support.
  echo            - Print arguments to stdout.
  edit            - Graphical text editor.
  extract         - Extract a TAR or TAR.GZ archive into a directory.
  fdisk           - Run the fdisk command.
  files           - Graphical file explorer.
  fontpreview     - Preview an OTF/TTF font in multiple sizes.
  format          - Run the format command.
  gui_demo        - Run the gui_demo command.
  hello           - Run the hello command.
  hello_c         - Print Hello World.
  history         - Show or clear command history.
  install         - Install, update, remove, and search packages.
  installer       - EYN-OS graphical installer.
  jobs            - List background jobs.
  jsonparse       - Parse and normalize JSON files.
  list            - List directory entries with terminal icons.
  metadata        - Show metadata for a file or directory.
  notify          - Show a graphical notification popup.
  pipe            - Run a command pipeline from userspace command launcher.
  random          - Generate random numbers.
  search          - Search for text in filenames and file contents.
  settings        - Open system settings (video + customization).
  sha256          - Compute SHA-256 digests for files or strings.
  snake           - Classic snake game with keyboard controls.
  sort            - Sort strings alphabetically.
  spam            - Spam 'EYN-OS' to stdout 100 times.
  ssh             - SSH client scaffold with banner+KEX smoke and PTY spawn smoke.
  tetris          - Play classic falling-block puzzle game.
  tiling          - Launch the tiling manager.
  view_backend_bmp - Run the view_backend_bmp command.
  view_backend_builtin - Open an REI, BMP image, REIV video, REIS audio, or WAV audio viewer.
  view_backend_rei - Run the view_backend_rei command.
  view_backend_reis - Play a REIS audio file in a dedicated backend.
  view_backend_reiv - Play a REIV video file in a dedicated backend.
  xeyes           - X11 xeyes - eyes that follow the mouse pointer.
